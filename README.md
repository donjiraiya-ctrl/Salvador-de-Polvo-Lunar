# Motion-Assisted Lunar Dust Mitigation and Resistive Grounding Interface

A Phase 1 preliminary engineering concept for reducing lunar-regolith contamination
and controlling electrostatic charge at an EVA interface.

## Concept

The system combines two passive functions:

1. **Motion-assisted dust mitigation** ‚Äî normal astronaut movement mechanically drives
   a compliant wiper/cam mechanism that clears loose dust from a designated interface
   before contact.
2. **Controlled resistive grounding** ‚Äî a high-value series-resistance path provides
   a controlled discharge route after the cleaning sequence and before structural
   engagement.
